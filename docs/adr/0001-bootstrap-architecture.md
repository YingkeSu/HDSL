# ADR 0001：初始架构与边界

日期：2026-09-20。状态：已采用。Electron + React + TypeScript 与受管运行时分离已在代码中实现；以下保留最初的决策背景。上游验证见[兼容性研究](../research/dsh-compatibility.md)。

## 背景

用户要简洁 UI、环境隔离和插件整合包，小团队需要降低语言与运行时维护成本。

## 决策

以 Electron + React + TypeScript 为首选，受管 Node/DSH 与应用运行时分离。一个共享领域上下文；先完成本地闭环，再做社区与微信小程序。初始只建文档与工作流，不生成空业务实现。

## 替代方案

Tauri 能减轻应用体积，但增加 Rust 和系统 WebView 差异成本；若实测 Electron 资源预算不可接受，再用 ADR 比较。直接改造现有 launcher 需先确认许可和架构适配成本，目前只借鉴模式。

## 后果

需承担 Electron 安全更新和跨平台打包；实际依赖版本、DSH 接口与资源预算在技术验证任务中锁定。隔离目录与代际提供可恢复性，不承诺 OS 沙箱。当前不决定 HDSL 自有代码的分发许可证。
